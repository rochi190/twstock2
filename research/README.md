# 研究實驗（不影響 app）

這個資料夾放的是「新訊號能不能提高預測」的實驗。app 本身不會用到這裡的任何程式；
只有實驗通過預先登記的門檻，才會考慮整合進模型。

## 實驗 flow-1：三大法人買賣超

規則在 [PROTOCOL.md](PROTOCOL.md)，執行前就寫死。它測試外資、投信、三大法人合計的買賣超，
能不能預測股票接下來 5 或 20 個交易日的相對漲跌。判定時要通過兩個測試才算數：換一批從沒用過的股票，以及換一段之後的時間。
通過後，還要在扣掉交易成本後勝過「全部股票平均買」。

### 怎麼執行（需要能上網的電腦）

在專案資料夾裡：

```bash
python3 -m venv .venv
.venv/bin/pip install numpy scipy
.venv/bin/python -m research.flow_experiment
```

* 第一次要下載約五年的證交所三大法人日報（每天一頁，為了不被證交所封鎖，每頁間隔 3.5 秒），
  加上約 100 檔股票的歷史股價，**大約需要 1~1.5 小時**。下載過的資料會存在 `data_cache/`，之後再跑只要幾分鐘。
* 如果出現「沒有下載成功……請過一段時間再執行」：證交所暫時擋了太頻繁的請求。等一小時後執行同一個指令即可，
  會從中斷處繼續。程式在資料不完整時**不會**給出結論，避免用殘缺資料下判斷。
* 跑完會在 `research/results/flow1_日期.md` 寫出結果表與結論（也會印在螢幕上）。把那個檔案的內容貼回來即可。

### 合成資料的自我檢查

```bash
.venv/bin/python -m unittest tests.test_research_flow     # 約 20 秒
.venv/bin/python -m research.simulate --reps 40           # 約 15 分鐘：誤報率與偵測力
```

2026-11-07 的模擬結果（每種強度 40 次，每次 80 檔、約 1,150 個交易日；「強度」= 訊號每高 1 個標準差，之後每天多出的報酬）：

| 植入強度（每天） | 至少一個訊號被判成立 | 最終判定「通過」 |
|---|---|---|
| 0（完全沒有訊號） | 0 / 40 | 0 / 40 |
| 0.05% | 40% | 17.5% |
| 0.10% | 92.5% | 92.5% |
| 0.20% | 100% | 100% |

160 次模擬中，沒有植入訊號的投信訊號（trust_20）一次都沒被誤判成立。「三大法人合計」（inst_5）偶爾成立是正確的，
因為它本來就包含了植入訊號的外資買賣超。結論：這套規則幾乎不會誤報，但只抓得到中等以上強度的訊號，
很弱的真實效果可能會被漏掉。
